# Security

This is the source of the Lusted website. If you find a security problem in it — anything that could expose a
customer's details, the shop's private photo store or the Vercel/Cloudflare accounts behind the site — please tell us
privately rather than opening a public issue.

**Report it** through GitHub's private vulnerability reporting: the **Security** tab of this repository → **Report a
vulnerability**. It reaches the maintainers only. Please include the page or file, what you observed, and steps to
reproduce it.

**What to expect:** an acknowledgement within 3 working days, and a fix or a mitigation before anything is disclosed.
We'll credit you in the advisory if you'd like.

**In scope:** this repository and the site it builds (lusted.vercel.app, lusted-dev.vercel.app). The photos the site
shows are not a vulnerability; the keys to the store they come from would be.

**Supported version:** the `main` branch, as deployed.
